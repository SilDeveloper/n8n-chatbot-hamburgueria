# Chatbot de Hamburgueria — n8n

Workflow demonstrativo de um atendente virtual para uma hamburgueria.

## Importar
1. Importe `workflow.json` no n8n.
2. Configure sua própria credencial no nó **OpenRouter Chat Model**.
3. Confira o caminho de gravação `/data/bot_hamburgueria.txt` e as permissões do ambiente antes de executar.

## Segurança
O JSON publicado não inclui o bloco de credenciais nem identificadores específicos da instância. Nunca adicione chaves de API, tokens, senhas ou dados reais de clientes ao repositório.
